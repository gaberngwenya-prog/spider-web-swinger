# Spider Swing

A mobile-friendly 2D web-swinging platformer inspired by classic city-spider action games.

## Play locally

1. Open the project folder in a browser.
2. Start a simple local server in the project root:

```bash
python3 -m http.server 8000
```

3. Open:

```text
http://localhost:8000
```

## Controls

- Desktop:
  - Move: A / D or Left / Right arrow keys
  - Jump: W, Up arrow, or Space
  - Swing / Web: S or Shift
- Mobile:
  - Use the on-screen control buttons

## Goal

Swing across rooftops and reach the glowing checkpoint on the far right.
